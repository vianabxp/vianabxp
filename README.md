## PERFIL

Me chamo **Guilherme** e sou focado no desenvolvimento front-end, com interesse na criação de interfaces modernas, responsivas e visualmente consistentes.

Busco unir desenvolvimento, design e experiência do usuário para construir aplicações web com personalidade própria, atenção aos detalhes e uma estrutura bem organizada.

Meu objetivo é transformar conceitos visuais em interfaces funcionais, explorando tecnologias modernas e aprimorando continuamente minhas habilidades. Também consigo trabalhar com back-end, embora essa não seja minha área principal.
